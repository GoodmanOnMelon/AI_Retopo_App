# AI Retopo Studio Pro

Дипломный проект, представляющий собой настольное приложение для интеллектуальной ретопологии 3D-моделей на основе графовых нейронных сетей.

Приложение использует комбинацию классических алгоритмов геометрического упрощения (полигональной децимации) и глубокого обучения на графах для определения наиболее значимых областей сетки, сохраняя мелкие детали и геометрию при сильном сжатии.

---

## Ключевые возможности

* **Интерактивный 3D-визуализатор:** Отображение оригинальной, математической и ИИ-ретопологизированной моделей с помощью PyVista и Qt.
* **Анализ геометрии (GNN-инференс):** Использование двуслойной сверточной сети `GCNConv` (PyTorch Geometric) для генерации карт важности вершин на основе координат, нормалей и кривизны сетки.
* **Интеграция с СУБД MongoDB:** Полный цикл сохранения исходных моделей, результатов децимации, вычисленных метрик (RMSE) и версионирования весов моделей в хранилище GridFS.
* **Модуль обучения (Train pipeline):** Возможность пошагового обучения GNN на наборе данных ModelNet40 с автоматическим вычислением кривизны.

---

## Архитектура проекта

Проект разработан в соответствии с шаблоном проектирования MVC (Model-View-Controller) и имеет следующую структуру:

* `/ai` — нейросетевой стек: архитектура GNN (`model.py`), препроцессинг фичей (`preprocessor.py`) и управляющий движок (`engine.py`).
* `/core` — бизнес-логика: контроллер (`controller.py`) взаимодействия интерфейса и ИИ, а также файловый менеджер (`file_handler.py`).
* `/data` — работа с базой данных MongoDB и GridFS (`db_manager.py`).
* `/ui` — графический интерфейс пользователя PyQt6 (`main_window.py`) и 3D-порт визуализации (`viewport.py` на базе PyVista).
* `main.py` — точка входа в приложение.
* `train_dataset.py` — скрипт обучения GNN на датасете ModelNet40.

## Стек технологий

* **Язык разработки:** Python 3.10+
* **Графический интерфейс:** PyQt6
* **3D Визуализация:** PyVista, PyVistaQt, Trimesh
* **Глубокое обучение:** PyTorch, PyTorch Geometric (PyG)
* **База данных:** MongoDB, PyMongo, GridFS
* **Математические вычисления:** NumPy, SciPy

## Инструкция по установке и запуску

### 1. Подготовка окружения
Склонируйте репозиторий и настройте виртуальное окружение:
```bash
git clone https://github.com/GoodmanOnMelon/AI_Retopo_App.git
cd AI_Retopo_App
python -m venv venv
```

Активируйте виртуальное окружение:
* **Windows:** `venv\Scripts\activate`
* **macOS/Linux:** `source venv/bin/activate`

### 2. Установка зависимостей
Установите необходимые библиотеки (версии PyTorch и PyG рекомендуется подбирать под вашу версию CUDA):
```bash
pip install torch trimesh pyvista pyvistaqt PyQt6 pymongo scipy numpy
```

### 3. Запуск СУБД
Убедитесь, что на локальном компьютере запущен сервер MongoDB на порту `27017` (или настройте подключение в файле `data/db_manager.py`).

### 4. Запуск приложения
```bash
python main.py
```

### 5. Обучение модели (опционально)
Для повторного обучения модели на датасете ModelNet40 поместите распакованный датасет в директорию `dataset/ModelNet40` и выполните:
```bash
python train_dataset.py
```
